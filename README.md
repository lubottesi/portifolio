# Portfolio

My personal portfolio site, in Portuguese: an intro with links to my resume and contact info, an "about me" section, hard skills with proficiency levels, services I offer, and project cards for [gerador](https://github.com/lubottesi/gerador), [ecoride](https://github.com/lubottesi/ecoride) and [escape](https://github.com/lubottesi/escape), each linking to the live site and the repo.

**Live:** https://lubottesi.github.io/portifolio/

## Stack

- HTML5
- CSS3 (with a separate media queries stylesheet for responsive layout)
- Vanilla JavaScript (hamburger menu, smooth scrolling between sections)

## Running locally

No build step - open `index.html` in a browser.
